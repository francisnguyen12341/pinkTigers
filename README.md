# pinkTigers
Git Repository for Pink Tigers Webpage Project

# Setup
### Installing Packages
```bash
npm install
```

### Create Database
1. Add your postgres password to env.json
2. If needed, update package.json scripts depending on your environment
3. Run the following command:
```bash
npm run setup
```

### Drop Database
```bash
npm run drop
```

### Run Server
```bash
npm run start
```
